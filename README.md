## About

Payment systems like PayPal, Apple Pay, Google Pay, Wise, Venmo, Revolut, and Alipay are widely used across the globe, offering secure and convenient ways to transfer money, make purchases, and manage finances. Despite operating under different names in various regions, they share key features such as peer-to-peer transfers, integration with bank accounts, support for multiple currencies, and seamless online and in-store payments. These systems serve as great inspiration for building a peer-to-peer payment API project.

In this project, you will build a simple version of a peer-to-peer payment system where users can send money to each other, check their account balances, and review their most recent transactions. The application will be developed using FastAPI to create a secure RESTful API, implementing authentication and authorization to ensure that only authorized users can access certain endpoints. The project will adhere to best practices for secure API development, including the use of token-based authentication and secure database interactions.

Estimated completion time is around **15 hours**.
